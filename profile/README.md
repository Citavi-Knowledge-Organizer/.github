# Citavi - Knowledge organizer for thesis projects and sources you already collected

## Citavi Highlights

- **Project, Not A Loose .bib:** Citavi reference project holds the sources for a thesis or paper you already write, with categories you designed.
- **Quotations You Excerpted:** Citavi quotation stores passages you copied from sources you have the right to use, with page numbers for the draft.
- **Tasks Beside The Reading:** Citavi knowledge organizer can list “read, excerpt, write” on items in Citavi academic workspace so a dissertation schedule is visible.
- **Word Workflow:** Many users insert citations from the project into a document they already typeset in Word, unlike a TeX-only manager.
- **Not A Bibliometric Map And Not An H-Index Desk:** Maps and metrics are other programs.

---

## What Is Citavi

Citavi is a Windows academic knowledge organizer. Graduate students and research groups who already collect PDFs open Citavi knowledge organizer to keep references, excerpts, and tasks together. Citavi reference project is the container. Citavi quotation is the excerpt with a pointer back to the source. Citavi academic workspace is the daily seat: categories, comments, and a path into Word.

JabRef is the better metaphor if you live in `.bib` and a compiler. Biblioscape is a notes-and-records database without Citavi’s task-and-category thesis culture. Publish or Perish counts. Citavi is where a chapter outline meets the library you built.

Put in sources you collected or were given permission to store. Quotations should be short enough for fair use or otherwise licensed, and marked as quotes. Do not dump a publisher’s entire ebook into the project.

## Starting with Citavi

Prerequisites: A licensed seat you administer and sources you are allowed to store for a project you write.

1. **Prepare:** Name the thesis or paper and list chapter headings you already planned.
2. **Configure:** Create Citavi reference project with those categories, and attach Word if that is your draft tool.
3. **Test:** Add one source, save a Citavi quotation with a page, and insert a citation in a test paragraph.
4. **Refine:** Add tasks in Citavi knowledge organizer for unread items you actually intend to finish.
5. **Apply:** Grow Citavi academic workspace as chapters proceed, excerpting only what you have a right to use.
6. **Maintain:** Backup the project with the draft, and archive after submission.

## Best Uses

- **Dissertation You Are Writing:** Citavi reference project mapped to chapters.
- **Seminar Paper With Word:** Quotations into a document you already typeset.
- **Group Project The Campus License Covers:** One Citavi academic workspace the team is allowed to share.
- **Hired Literature Support:** Only sources the client delivered.
- **Not A TeX-Only .bib:** Use JabRef beside the compiler.
- **Not A Science Map:** Use VOSviewer.
- **Mark Quotes As Quotes:** Citavi quotation should never look like your prose.
- **One Project Per Title:** Mixing two theses hides tasks.
- **Page Numbers On Every Excerpt:** Future you will need them.
- **Fair-Use Length:** Do not store whole books you did not license.
- **Task List Honest To The Week:** Citavi knowledge organizer is useless if every item is overdue forever.
- **Backup Before A Committee Draft:** The project is part of the thesis pile.
- **Categories Before Mass Import:** Citavi reference project should have chapter buckets first.
- **Core Versus Peripheral Reading:** Tag in Citavi knowledge organizer so tasks stay ranked.
- **Word Styles From The Faculty Template:** Insert citations into a document you already format that way.
- **Group Roles If The License Allows:** Who may delete a Citavi quotation should be explicit.
- **Abstract Versus Excerpt:** Keep your summary separate from quoted words.
- **End-Of-Chapter Sweep:** Unread tasks in Citavi academic workspace should be honest before you submit.
